# Benchmark моделей Polza

Benchmark запускается отдельно от CRM и не создаёт полисы, платежи или другие
бизнес-объекты. Production-корпус хранится только в закрытом каталоге
`/var/lib/crm3/ai-diagnostics/benchmark-*` (каталог `0700`, файлы `0600`) и
удаляется через семь дней.

Сначала выполняется dry-run:

```text
python benchmark_run.py --run-dir /var/lib/crm3/ai-diagnostics/benchmark-<run> --stage 1 --dry-run
```

Платный запуск принимает ключ только из stdin (`--key-stdin`), не из argv,
файла или production `.env`. В runner включён fail-closed бюджет: рабочий
лимит 270 ₽, абсолютный лимит 300 ₽. Ответ без точного `usage.cost_rub`
блокирует продолжение до ручной сверки в кабинете Polza. После сбоя запрос не
повторяется автоматически, пока списание не подтверждено. Оставшийся ledger
нельзя удалять без проверки отсутствия работающего runner.

Эталоны размечаются вручную по страницам PDF. Даты, деньги и остальные поля
оцениваются с весами 50/25/25; неоднозначные поля исключаются явно. Первый
плановый платёж проверяется отдельно на равенство `start_date`. Итоговый
рейтинг применим только к фактически завершённым моделям и указывает размер
выборки и реальные списания.
